# Sprints

Sprint-scoped material lives here — boards, demo scripts, review notes. One folder per
sprint, so "what happened in sprint N?" is a directory listing rather than an archaeology
exercise.

| Sprint | Dates | Folder | Theme |
|---|---|---|---|
| 1 | → 13 Aug 2026 | [`sprint-1/`](sprint-1/) | Research, survey, the July analysis, two decks. **Predates this repo** |
| 2 | 17–28 Aug 2026 | [`sprint-2/`](sprint-2/) | Build the agent: backend, AI pipeline, chat + voice |

## What does *not* go in here

**ADRs** (`../adr/`) are permanent and cross-cutting. A decision made in sprint 2 still
governs sprint 5, so filing them by sprint would bury them. Same for
[`../decision-log.md`](../decision-log.md), which is one running list.

Rule of thumb: if it stops being true when the sprint ends, it goes in a sprint folder.
If it stays true, it doesn't.
