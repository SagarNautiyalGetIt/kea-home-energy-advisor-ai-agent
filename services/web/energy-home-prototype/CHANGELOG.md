# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-23

### Added

- Interactive React 19 home-energy prototype.
- Live Open-Meteo weather and geocoding.
- SunCalc-based solar and lunar positioning.
- Deterministic energy dispatch with battery, grid, EV, outage, and curtailment states.
- GSAP-powered, source-coloured energy-flow animation.
- Five visual scenario presets and configurable home settings.
- 23 automated tests across energy, weather, astronomy, and scenario behavior.
- Public documentation, CI, security policy, issue templates, and MIT licensing.
